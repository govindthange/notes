# Ichimoku Components

Tenken-Sen: The Blue `Conversion Line`.
Kijun-Sen: The Red `Baseline`.
Tenken-Sen/Kijun-Sen Cross (TK Cross): The Conversion and Baseline Crossover
Chikou Span: The Pink `Lagging Span` Line.
Kumo: The Cloud
