# Dual Thrust Calendar Spread (DTCS)

In this strategy we buy a near-term ATM option contract and simultaneously sell a longer-term ATM option contract of the same type.
- It is called a "calendar call spread" if we buy the near-term CE and sell longer-term CE option.
- It is called a "calendar put spread" if we buy the near-term PE and sell longer-term PE option.
