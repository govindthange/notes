# 📐 Trigonometry Formulas & Identities

## I. Fundamental Identities

* Reciprocal Identities: $\csc \theta = \frac{1}{\sin \theta}, \sec \theta = \frac{1}{\cos \theta}, \cot \theta = \frac{1}{\tan \theta}$

* Quotient Identities: $\tan \theta = \frac{\sin \theta}{\cos \theta}, \cot \theta = \frac{\cos \theta}{\sin \theta}$

* Pythagorean Identities: $\sin^2 \theta + \cos^2 \theta = 1$

* Pythagorean Identities (Secant-Tangent): $1 + \tan^2 \theta = \sec^2 \theta$

* Pythagorean Identities (Cosecant-Cotangent): $1 + \cot^2 \theta = \csc^2 \theta$

## II. Compound Angle Formulas

* Sine of Sum and Difference: $\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$

* Cosine of Sum and Difference: $\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$

* Tangent of Sum and Difference: $\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$

* Cotangent of Sum and Difference: $\cot(A \pm B) = \frac{\cot A \cot B \mp 1}{\cot B \pm \cot A}$

* Sine of Three Angles: $\sin(A + B + C) = \sin A \cos B \cos C + \cos A \sin B \cos C + \cos A \cos B \sin C - \sin A \sin B \sin C$

* Cosine of Three Angles: $\cos(A + B + C) = \cos A \cos B \cos C - \sin A \sin B \cos C - \sin A \cos B \sin C - \cos A \sin B \sin C$

* Tangent of Three Angles: $\tan(A + B + C) = \frac{S_1 - S_3}{1 - S_2}$ (where $S_1 = \sum \tan A, S_2 = \sum \tan A \tan B, S_3 = \tan A \tan B \tan C$)

## III. Multiple and Sub-Multiple Angle Formulas

* Double Angle Sine: $\sin(2\theta) = 2 \sin \theta \cos \theta = \frac{2 \tan \theta}{1 + \tan^2 \theta}$

* Double Angle Cosine: $\cos(2\theta) = \cos^2 \theta - \sin^2 \theta = 2\cos^2 \theta - 1 = 1 - 2\sin^2 \theta = \frac{1 - \tan^2 \theta}{1 + \tan^2 \theta}$

* Double Angle Tangent: $\tan(2\theta) = \frac{2 \tan \theta}{1 - \tan^2 \theta}$

* Triple Angle Sine: $\sin(3\theta) = 3 \sin \theta - 4 \sin^3 \theta$

* Triple Angle Cosine: $\cos(3\theta) = 4 \cos^3 \theta - 3 \cos \theta$

* Triple Angle Tangent: $\tan(3\theta) = \frac{3 \tan \theta - \tan^3 \theta}{1 - 3 \tan^2 \theta}$

* Half Angle Formulas (Sine): $\sin^2\left(\frac{\theta}{2}\right) = \frac{1 - \cos \theta}{2}$

* Half Angle Formulas (Cosine): $\cos^2\left(\frac{\theta}{2}\right) = \frac{1 + \cos \theta}{2}$

* Half Angle Formulas (Tangent): $\tan^2\left(\frac{\theta}{2}\right) = \frac{1 - \cos \theta}{1 + \cos \theta}$

## IV. Transformation Formulas

* Product to Sum (Sine-Cosine): $2 \sin A \cos B = \sin(A + B) + \sin(A - B)$

* Product to Sum (Cosine-Sine): $2 \cos A \sin B = \sin(A + B) - \sin(A - B)$

* Product to Sum (Cosine-Cosine): $2 \cos A \cos B = \cos(A + B) + \cos(A - B)$

* Product to Sum (Sine-Sine): $2 \sin A \sin B = \cos(A - B) - \cos(A + B)$

* Sum to Product (Sine Sum): $\sin C + \sin D = 2 \sin\left(\frac{C + D}{2}\right) \cos\left(\frac{C - D}{2}\right)$

* Sum to Product (Sine Difference): $\sin C - \sin D = 2 \cos\left(\frac{C + D}{2}\right) \sin\left(\frac{C - D}{2}\right)$

* Sum to Product (Cosine Sum): $\cos C + \cos D = 2 \cos\left(\frac{C + D}{2}\right) \cos\left(\frac{C - D}{2}\right)$

* Sum to Product (Cosine Difference): $\cos C - \cos D = -2 \sin\left(\frac{C + D}{2}\right) \sin\left(\frac{C - D}{2}\right)$

## V. Trigonometric Equations & General Solutions

* Sine Equation: $\sin \theta = \sin \alpha \implies \theta = n\pi + (-1)^n \alpha$ (where $n \in \mathbb{Z}$)

* Cosine Equation: $\cos \theta = \cos \alpha \implies \theta = 2n\pi \pm \alpha$ (where $n \in \mathbb{Z}$)

* Tangent Equation: $\tan \theta = \tan \alpha \implies \theta = n\pi + \alpha$ (where $n \in \mathbb{Z}$)

* Squared Sine Equation: $\sin^2 \theta = \sin^2 \alpha \implies \theta = n\pi \pm \alpha$ (where $n \in \mathbb{Z}$)

* Squared Cosine Equation: $\cos^2 \theta = \cos^2 \alpha \implies \theta = n\pi \pm \alpha$ (where $n \in \mathbb{Z}$)

* Squared Tangent Equation: $\tan^2 \theta = \tan^2 \alpha \implies \theta = n\pi \pm \alpha$ (where $n \in \mathbb{Z}$)

## VI. Inverse Trigonometric Functions

* Domain and Principal Ranges: $\sin^{-1} x: [-1, 1] \to [-\frac{\pi}{2}, \frac{\pi}{2}]$, $\cos^{-1} x: [-1, 1] \to [0, \pi]$, $\tan^{-1} x: \mathbb{R} \to (-\frac{\pi}{2}, \frac{\pi}{2})$

* Complementary Angles: $\sin^{-1} x + \cos^{-1} x = \frac{\pi}{2}$ (for $x \in [-1, 1]$)

* Complementary Angles (Sec-Csc): $\sec^{-1} x + \csc^{-1} x = \frac{\pi}{2}$ (for $|x| \geq 1$)

* Complementary Angles (Tan-Cot): $\tan^{-1} x + \cot^{-1} x = \frac{\pi}{2}$ (for $x \in \mathbb{R}$)

* Reciprocal Arguments: $\sin^{-1}\left(\frac{1}{x}\right) = \csc^{-1} x$ (for $|x| \geq 1$)

* Negative Arguments: $\sin^{-1}(-x) = -\sin^{-1} x$, $\tan^{-1}(-x) = -\tan^{-1} x$, $\cos^{-1}(-x) = \pi - \cos^{-1} x$

* Sum of Inverse Tangents: $\tan^{-1} x + \tan^{-1} y = \tan^{-1}\left(\frac{x + y}{1 - xy}\right)$ (if $xy < 1$)

## VII. Properties of Triangles

* Sine Rule: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ (where $R$ is circumradius)

* Cosine Rule: $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$

* Projection Rule: $a = b \cos C + c \cos B$

* Napier's Analogy (Tangent Half-Angle): $\tan\left(\frac{B - C}{2}\right) = \frac{b - c}{b + c} \cot\left(\frac{A}{2}\right)$

* Half-Angle Formulas (Sine): $\sin\left(\frac{A}{2}\right) = \sqrt{\frac{(s - b)(s - c)}{bc}}$, where $s = \frac{a + b + c}{2}$

* Half-Angle Formulas (Cosine): $\cos\left(\frac{A}{2}\right) = \sqrt{\frac{s(s - a)}{bc}}$

* Area of Triangle (Heron's Formula): $\Delta = \sqrt{s(s - a)(s - b)(s - c)} = \frac{1}{2}bc \sin A = \frac{abc}{4R} = r s$ (where $r$ is inradius)
