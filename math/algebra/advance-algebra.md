# 🔢 Advanced Algebra Identities & Formulas

## I. Complex Numbers

* Complex Number Form: $z = a + bi$ (where $i^2 = -1$)

* Complex Conjugate: $\bar{z} = a - bi$

* Magnitude / Modulus: $|z| = \sqrt{a^2 + b^2}$

* Multiplication of Complex Numbers: $(a + bi)(c + di) = (ac - bd) + (ad + bc)i$

* Polar Form: $z = r(\cos \theta + i \sin \theta) = re^{i\theta}$

* De Moivre's Theorem: $[r(\cos \theta + i \sin \theta)]^n = r^n(\cos(n\theta) + i \sin(n\theta))$

## II. Matrices and Determinants

* Determinant of a 2x2 Matrix: $\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$

* Inverse of a 2x2 Matrix: $A^{-1} = \frac{1}{ad - bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$ (where $ad - bc \neq 0$)

* Matrix Multiplication Dimension Rule: For $A$ ($m \times n$) and $B$ ($n \times p$), the product $AB$ is of dimension $m \times p$

* Matrix Inverse Property: $A A^{-1} = A^{-1} A = I$

## III. Inequalities and Absolute Values

* Addition Property: If $a > b$, then $a + c > b + c$

* Multiplication by Positive: If $a > b$ and $c > 0$, then $ac > bc$

* Multiplication by Negative: If $a > b$ and $c < 0$, then $ac < bc$ (inequality sign reverses)

* Absolute Value Definition: $|x| = x$ if $x \geq 0$, and $|x| = -x$ if $x < 0$

* Absolute Value Inequality (Less Than): $|x| < c \iff -c < x < c$ (where $c > 0$)

* Absolute Value Inequality (Greater Than): $|x| > c \iff x > c \text{ or } x < -c$ (where $c > 0$)

## IV. Partial Fraction Decomposition

* Distinct Linear Factors: $\frac{P(x)}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b}$

* Repeated Linear Factors: $\frac{P(x)}{(x - a)^2} = \frac{A}{x - a} + \frac{B}{(x - a)^2}$

* Irreducible Quadratic Factor: $\frac{P(x)}{(x - a)(x^2 + bx + c)} = \frac{A}{x - a} + \frac{Bx + C}{x^2 + bx + c}$
